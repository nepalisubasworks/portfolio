# Subas Nepali — Developer Portfolio

Next.js 15 (App Router) · strict TypeScript · Tailwind CSS v4 · pnpm

## Run it

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # production build
```

## Things to personalise
- `constant/constant.ts` — email, phone, social links, project links, all section content
- `public/images/` — replace `avatar.svg` and `project-*.svg` with real images (update paths in constant.ts)
- `public/cv/Subas-Nepali-CV.pdf` — replace the placeholder with your real CV
